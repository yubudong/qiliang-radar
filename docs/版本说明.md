# 起量雷达 v0.1.6

交付形式：Tampermonkey 用户脚本，非独立 CRX 扩展。

## 包含的功能

- 店铺列表显示销量采集、自动滚动及查看更多。
- 可调最低累计销量、每日本地记录、昨日对比。
- 四项趋势指标、新星筛选。
- 店铺名和日期命名的 CSV。
- 已扫描、保存成功、低门槛跳过、未展示销量、失败商品分类统计。

## 验证范围

用户已反馈早期版本正常启动、采集与导出，以及 v0.1.3 自动加载修复成功。v0.1.6 本地自动化测试通过；趋势计算使用合成历史测试。尚不能宣称所有店铺、多日真实增量或长期稳定性均完成验证。

本包只含构建脚本与文档，不包含用户数据。脚本本身没有远程运行时依赖、自动更新地址或独立云端服务。升级由使用者手动替换。
