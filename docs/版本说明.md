# 起量雷达 v0.1.7-beta.3

> **适用范围：桌面 Chrome + Tampermonkey，Temu 美国站（US）店铺商品列表。v0.1.7-beta.3 加入英语、西班牙语、法语、葡萄牙语、俄语、阿拉伯语、韩语、简体中文及繁体中文的解析规则。九语言本地测试通过；8种语言已实测采集与CSV导出，西班牙语受网站店铺不可用阻挡，尚未验收。自动翻页及长期稳定性不在本轮实测结论内。**
>
> 站点须为美国。插件界面仍为中文；不同页面语言的采集历史分开保存，切换语言后首次采集需要重新建立基线。

交付形式：Tampermonkey 用户脚本，非独立 CRX 扩展。

## 包含的功能

- 店铺列表显示销量采集、自动滚动及查看更多。
- 可调最低累计销量、每日本地记录、昨日对比。
- 四项趋势指标、新星筛选。
- 店铺名和日期命名的 CSV。
- 已扫描、保存成功、低门槛跳过、未展示销量、失败商品分类统计。

## 验证范围

用户已反馈早期版本正常启动、采集与导出，以及 v0.1.3 自动加载修复成功。v0.1.7-beta.3 本地自动化测试通过；趋势计算使用合成历史测试。尚不能宣称所有店铺、多日真实增量或长期稳定性均完成验证。

本包只含构建脚本与文档，不包含用户数据。脚本本身没有远程运行时依赖、自动更新地址或独立云端服务。升级由使用者手动替换。

## 多语言测试版变更

新增九语言识别、数字格式与加载按钮规则；修复英文商品总数与标题拼接导致的识别失败，兼容实际英文无空格销量文案。CSV 增加页面语言列，面板标明当前语言。

完整证据和未完成项见[多语言测试报告](多语言测试报告.md)。这不是九语言全流程验收通过的正式版。
