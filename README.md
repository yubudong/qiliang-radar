# 起量雷达

> **适用范围：桌面 Chrome + Tampermonkey，Temu 美国站（US）店铺商品列表。v0.1.7-beta.4 加入英语、西班牙语、法语、葡萄牙语、俄语、阿拉伯语、韩语、简体中文及繁体中文的解析规则。九语言本地测试通过；8种语言已实测采集与CSV导出，西班牙语首批采集与CSV导出通过，加载更多时网站显示店铺不可用，全店采集未通过。自动翻页及长期稳定性不在本轮实测结论内。**
>
> 站点须为美国。插件界面仍为中文；不同页面语言的采集历史分开保存，切换语言后首次采集需要重新建立基线。

**Temu 竞品商品显示销量趋势观察工具。** 每天记录竞品店铺商品的显示销量，比较增量，发现持续增长、正在起量的候选商品。

当前试用版本：**v0.1.7-beta.4**。文档整理日期：2026-10-01。

## 适合谁，解决什么问题？

| 使用人群 | 常见问题 | 帮助 |
|---|---|---|
| Temu 店铺运营 | 每天逐个查看竞品耗时，昨天的数据难以记住 | 自动加载店铺列表，保留每日记录并比较 |
| 选品人员 | 累计销量高不等于最近起量 | 观察近期增量、连续增长和增速变化 |
| 个人卖家、小团队 | 不想部署服务器或搭建复杂数据系统 | 在浏览器内完成采集、分析、CSV导出 |
| 竞品研究人员 | 截图零散，难以形成连续记录 | 按店铺、商品和日期积累可导出的数据 |

## 功能特色

- 自动滚动、识别店铺“查看更多”并加载后续商品，未采全时提示。
- 最低累计销量默认20件，可调整；它不是采集数量上限。
- 昨日参考、今日参考、参考增量，按北京时间自然日比较。
- 近3日均增量、连续增长天数、增速变化、首次发现日期。
- 新星筛选：首次发现7个自然日内、连续增长至少2天、增速变化为正。
- 分开统计扫描、保存成功、低门槛跳过、未展示销量和失败商品。
- CSV文件名包含店铺名及日期；记录保存在当前浏览器本地。

## 5分钟上手

1. 在电脑Chrome安装官方Tampermonkey，按提示开启“允许用户脚本”。
2. 从上方 Releases 下载试用ZIP并解压，用文本编辑器打开 `.user.js` 文件。
3. Tampermonkey → 添加新脚本 → 替换全部默认代码 → 粘贴文件全文并保存。
4. 打开Temu美国站、上述语言之一的店铺商品列表页，刷新确认面板出现。
5. 核对店铺名，设置最低销量并点击“开始”。等待结束后检查是否采全，导出CSV。
6. 次日在相近时间再次采集；积累连续5天有效记录后，才有完整的增速变化指标。

只需安装油猴和脚本，不需要Node.js或服务器。详细按钮、权限和故障处理见[使用说明](docs/使用说明.md)。

## 指标怎么理解？

假设连续5天显示累计销量为20、22、26、32、42，日增量为2、4、6、10：

- 今日增量：10。
- 近3日均增量：(4+6+10)/3，约6.7。
- 增速变化：10−(2+4+6)/3，约6。
- 连续增长至少4天；首次发现不等于上架日期。

缺采不补零，历史不足显示“数据不足”。新星只是值得进一步查看的候选商品，不是爆款保证。

## 使用边界

本测试版面向美国站九种页面语言；真实页面验证范围见版本说明。其他平台、地区和手机端未完成验证。需要每天手动打开店铺并开始，不是无人值守定时监控。

**显示销量增量不是后台真实日订单。** 万级显示值可能取整，数据可能延迟；无销量标签不代表零销量。不使用SKU汇总作为精确商品总销量，也不自动进入详情页补采。

网站结构、验证或网络变化可能影响采集，不能承诺长期免维护或所有店铺采全。当前无云同步、无CSV恢复导入。更新请编辑原脚本条目，避免先删除旧脚本。

## 给开发者

要求Node.js 24+。在仓库根目录运行：

```bash
npm ci
npm run build
npm test
node --check dist/qiliang-radar.user.js
```

源码在 `src/`，测试在 `tests/`，安装产物在 `dist/`。2026-10-01重新构建，105项本地测试通过；不等于多日真实数据或所有店铺均已验证。
